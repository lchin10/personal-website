# personal-website

my personal website, built with [Astro](https://astro.build).

```sh
npm install
npm run dev      # http://localhost:4321
npm run build    # static site in dist/
```

- Content (experience, projects, skills, photo lists): `src/data.ts`
- Colorways and garment drawings: `src/garment.ts`
- Pages: `src/pages/`, shared nav/footer and client script: `src/layouts/Base.astro`
- Photos: `public/img/`
